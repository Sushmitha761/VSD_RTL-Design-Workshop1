##  Overview

This repository contains my implementation and documentation of the VSD Physical Design Workshop using OpenLane and the Sky130 PDK. It demonstrates the complete RTL-to-GDSII ASIC design flow using open-source EDA tools.


##  Tools Used

- Ubuntu 20.04
- Oracle VirtualBox
- Docker
- OpenLane
- OpenROAD
- Yosys
- Magic VLSI
- Sky130 PDK

##  Workshop Modules

- Environment Setup
- RTL Synthesis
- Floorplanning
- Placement
- Cell Design
- Characterization
- Static Timing Analysis
- CTS
- Routing
- DRC & LVS

##  Repository Structure

- Day 1 – Environment Setup
- Day 2 – Floorplanning
- Day 3 – Placement & Cell Design
- Day 4 – Timing Analysis
- Day 5 – Routing & Physical Verification
