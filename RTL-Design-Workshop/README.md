# VSD RTL Design Workshop

## 1. Overview

This section documents my learning and practical work from the VSD RTL Design Workshop. It covers RTL design concepts, Verilog HDL, simulation, functional verification, and the RTL-to-synthesis workflow.

The repository is organized module-wise to make the learning process, practical exercises, and observations easy to review.

## 2. Objectives

- Understand the fundamentals of RTL design.
- Learn how digital hardware is described using Verilog HDL.
- Understand the role of testbenches in functional verification.
- Explore simulation and waveform analysis.
- Understand the relationship between RTL code and synthesized hardware.
- Document module-wise practical exercises and observations.

## 3. Tools and Technologies

## 5. Typical RTL Workflow

1. Understand the design requirements.
2. Write the RTL module in Verilog.
3. Develop a testbench to verify the design.
4. Compile and run the simulation.
5. Inspect the simulation output and waveforms.
6. Fix functional issues if any are found.
7. Run synthesis when applicable.
8. Review the synthesis output and document observations.

## 6. Practical Work and Evidence

Each module's documentation should include the topics studied, source files where applicable, testbench and simulation evidence where available, screenshots or waveforms, and observations from the practical exercises.

Only results that were actually executed and verified should be reported.

## 7. Learning Outcomes

Through this workshop, I developed an understanding of RTL design, Verilog-based hardware description, functional simulation, testbench-based verification, and the purpose of logic synthesis.

## 8. Conclusion

This workshop provides a foundation for understanding the digital design flow from RTL description and verification to synthesis. The module folders contain the corresponding workshop material and practical documentation.
